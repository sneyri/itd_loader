# Как мне загрузить свой баннер?
Для начала вам нужно достать refresh_token с сайта итд.com. Он лежит в куках сайта
Дальше в корне проекта нужно создать файл .cookies, и в нем вставить этот самый токен в формате refresh_token=ТОКЕН; is_auth=1;
После этого устанавливайте зависимости через команду npm install и после запускайте скрипты через команду node ./скрипт
